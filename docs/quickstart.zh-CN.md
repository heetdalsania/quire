# Quire 简体中文入门

[English README](../README.md)

Quire 把本地 Markdown 文件夹变成可协作的编辑空间。你可以与其他人、通过 MCP 连接的
AI 智能体一起编辑，查看作者归属，审核修改建议，并移除某个作者添加的内容。
原始 `.md` 文件仍保存在你的电脑上。

## 先试用示例

安装 Node.js 22 或更新版本，在终端运行：

```sh
npx quiredocs@latest --demo
```

保留终端运行，在同一台电脑的浏览器中打开终端显示的地址，通常是
`http://127.0.0.1:4321`。`--demo` 使用临时示例文件，不会打开你的个人笔记。

编辑自己的文件夹：

```sh
npx quiredocs@latest "/你的/Markdown文件夹"
```

Quire 会把已确认的修改写回文件。建议先备份重要文档或使用 Git。

## 连接智能体

保持 Quire 运行，在你使用的客户端中添加 MCP 配置。例如：

```sh
claude mcp add quire -- npx -y -p quiredocs@latest quire-mcp --url http://127.0.0.1:4321 --name "Claude Code"
```

Codex 和 Cursor 的配置，以及原生 Windows 的命令，见 [连接说明](../README.md#connecting-an-agent)。
端口必须与正在运行的 Quire 相同。配置后重启或重新加载客户端。

可以向智能体发送：

> 使用 Quire MCP 读取 welcome.md。用 edit_document 的 suggest=true 提出一处小的措辞改进。
> 不要直接修改磁盘上的文件，也不要接受建议。由我审核。

选择对应的文件，在修改建议面板接受或拒绝。智能体访问文档后，其在线身份才会出现在该文档中；
仅保存客户端配置并不表示智能体已经连接。

## 界面语言预览

当前开发版新增了文档库侧栏底部的语言选择器和“连接智能体”入口；手机上先打开文件视图。
这些界面更新尚未随 npm beta.4 发布。简体中文覆盖核心导航、审核操作和连接窗口；高级菜单、
部分提示和示例任务仍为英文。翻译是 AI 辅助初稿，欢迎母语使用者提出修订。
切换界面语言不会翻译、重写或重新加载你的文档。

## 隐私、费用和限制

- Quire 免费、开源，无 Quire 账号和遥测。首次 npx 运行会从 npm 下载软件包。
- AI 客户端和模型供应商是独立服务，可能需要账号、收费，并接收其读取的文档内容。
- 仅连接你信任的智能体，并只打开你愿意授权给它的文件夹。
- 默认只监听本机；不要在未理解访问控制的情况下暴露到公网。
- 预览中的远程图片可能访问图片服务器；可选 Discover 功能也会访问外部仓库。
- 按作者撤销会移除该作者添加的文字，不能恢复其直接删除的原文。需要先审核的修改请用建议模式。
- 仍处于 beta 阶段。复杂输入法、所有语言及从右向左排版并未获得全面人工验证。

遇到问题请在 [GitHub Issues](https://github.com/heetdalsania/quire/issues) 提供操作系统、Node.js
版本、浏览器、复现步骤和脱敏后的示例。请勿上传个人文档、密码或访问令牌。
